# Changelog

All notable changes to this project are documented here.

## [1.0.0] - Initial release

- Add offline-first JSON Schema validation API and command-line interface.
- Support text and JSON output, file input, and standard input.
- Reject external schema references.
- Add synthetic telemetry examples, unit tests, and CLI tests.
- Add Python 3.10–3.13 CI and container smoke tests.
- Add manual and tag-triggered multi-architecture GHCR publication.
